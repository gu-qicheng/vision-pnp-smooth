# 110 mm 正方形手工点击 PnP 设计规范

## 目标

在 Windows 上打开设备 0 的 1920×1080 摄像头画面，首击冻结当前帧，按 TL → TR → BR → BL 点击 110 mm 正方形外轮廓四角，使用平面 PnP 计算目标中心在摄像头坐标系中的 X/Y/Z，并在 1280×720 预览中叠加坐标轴。

## 坐标与输入契约

- 标定文件：`camera_calibration.npz`。
- 必须读取 `camera_matrix`、`dist_coeffs`、`image_size`，且图像尺寸为 1920×1080。
- 对象点（mm）：TL(-55,-55,0)、TR(55,-55,0)、BR(55,55,0)、BL(-55,55,0)。
- 目标坐标：中心为原点，X 向右、Y 向下、Z 远离镜头。
- OpenCV `tvec` 表示目标中心在摄像头坐标系中的位置，不转换成摄像头位置。

## 运行行为

- 摄像头设备 0，严格检查实际帧为 1920×1080。
- 预览缩放为 1280×720，点击坐标按比例映射回原图。
- 首次左键点击时冻结帧，后续三点均在该帧上选择。
- 使用 `solvePnPGeneric(..., SOLVEPNP_IPPE)`，保留正深度解并按重投影 RMS 选择。
- RMS 大于 5 px 或无合法候选时显示无效状态，不显示伪姿态。
- `R` 清除冻结帧、四点和旧姿态；`Esc` 退出。
- 不包含 YOLO、自动检测、跟踪或动态目标更新。
